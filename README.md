# Keyword-Website-Blocker
Blocks websites containing saved keywords.

Keyword Website Blocker gives you total control over your browsing habits. Effortlessly block websites by defining custom keywords—if a URL contains any of your blocked terms, access is instantly denied. Stay focused, remove distractions, and build better digital habits.

# Key Features:

Smart Keyword Matching: Block individual words or phrases instead of typing out dozens of specific URLs.

Instant Page Interruption: Automatically stops blocked sites from loading right at document start.

Simple Management: Easily add or remove blocked terms from your browser popup interface at any time.

Lightweight & Fast: Runs quietly in the background without slowing down your browser.

Perfect for studying, deep work sessions, or breaking unwanted web browsing habits.
